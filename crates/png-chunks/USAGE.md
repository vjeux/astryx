`png-chunks [--quiet] [--allow TYPE]... <file or directory>...` lists each PNG's chunk types and fails a PNG that carries any chunk outside the content-free types `IHDR PLTE IDAT IEND tRNS gAMA cHRM sRGB sBIT pHYs bKGD hIST`, or bytes after `IEND`: text, Exif, a timestamp, an ICC profile or a private chunk can each carry what must not leak, so only the known-safe types pass. `--allow TYPE` (four letters, repeatable, also `--allow=TYPE`) accepts one more type, such as `iCCP`. Each PNG gets one line with its chunk types in file order (a run of one type as `IDAT×7`); a failing PNG gets a second line, `  METADATA: …`, naming each chunk with its byte offset: a text chunk (`tEXt`, `iTXt`, `zTXt`) with its keyword, whose text is never printed, `eXIf` and `tIME` by name, and any other type as `unknown chunk TYPE`. Every chunk's length, type and CRC is checked, the first chunk must be `IHDR` and an `IEND` must end the file, so a damaged or misread file is UNREADABLE, never a pass. A directory is walked in sorted order through symbolic links; a link back into a directory being walked, a broken link and a directory that cannot be listed are UNREADABLE, and each file whose name does not end in `.png` (any case) is named as `not checked` and counted in the summary without failing the run. A file named directly is read whatever its name. The last line is the summary: `N PNGs: C clean, M with metadata, U unreadable` plus `; K other files not checked` when there are some. `--quiet` prints only the failing, unreadable and unchecked files and the summary. Exit 0 when every PNG is clean, 1 when a PNG fails, 2 on a usage error, an unreadable file or no PNG found.

Checked (test data) on #12238's third re-take set (`evidence/12238-retake3-stills-2026-11-18` at `7649dae58a`): 184 PNGs, 184 clean (33 `IHDR IDAT IEND`, 151 `IHDR IDAT×N IEND`) and its `labels.md` named as not checked, the same as `identify -verbose`, which finds no text, time or Exif property in any of the 184. A PNG that ImageMagick writes with `-set comment` fails with its `tIME` and its `tEXt "comment"`; one of the 184 with a private `prIv` chunk spliced in (valid CRC) fails as `unknown chunk prIv`, and passes with `--allow prIv`. std only; `cargo test --release` runs the chunk, CRC, allowlist and damage cases and the command end to end, links and loops included.
