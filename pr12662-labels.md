# #12662 Tab hover and press layer: stills (test data, local Storybook builds)

- Builds, with stamps read back from each served build: main 8d375af8d6849244ba21daa5a79aa56c73084d7d, head c05fbaeb35b38db1bf81751a9d30615c9d72cc41. Main is the head's merge-base. The TabList stories are the same file at both builds.
- Browsers: Playwright chromium 149.0.7827.55 and firefox 151.0. Desktop: viewport 1400×900, deviceScaleFactor 2, mouse. Light and dark (the Storybook global `colorMode`, with the browser's color scheme to match). Both engines report `(hover: hover)` and `(pointer: fine)` in every take.
- Hover: the mouse moves onto the control. Press: the mouse moves to the control's centre and its button goes down and stays down for the still. Rest: the mouse stays at (2, 2), outside the strip. Each take loads the story fresh. A still is taken once two screenshots 100 ms apart are equal.
- Test-only overrides, each one `<style>` tag added to the page after the story renders and before the pointer moves:
  - "forced opaque": `#storybook-root * { --color-overlay-hover: rgb(255, 0, 255) !important; }`
  - hover reference: `#storybook-root * { --color-overlay-hover: transparent !important; }`
  - press reference: `#storybook-root * { --color-overlay-hover: transparent !important; --color-overlay-pressed: transparent !important; }`
- How the stills are read. The label box is the box of the control's visible text span; the chevron box is its svg.
  - Forced opaque: a pixel in the box counts as not the overlay when |R − 255| + G + |B − 255| > 60. This is the rule of the PR's own spec. When the layer is under the label, the label's glyphs give such pixels. When an opaque layer is above the label, no pixel in the box differs.
  - Default overlay (hover and press): each still is compared with its reference still, which has the same state with the layer transparent. Distance is the largest channel difference. The box's background colour is the most common colour on its edge pixels in the reference. Glyph cores are the reference pixels at 90% or more of the box's largest distance from that colour. A core pixel counts as changed when a channel differs from the reference by more than 2. A layer under the label leaves the cores untouched; a layer above it tints them.
  - The selected tab at rest: the head's still is compared with main's, byte for byte.
- In TabMenu.tsx, the trigger's layer style has a :hover rule and no :active rule, at both builds. While the mouse is held down on the trigger, the layer keeps the hover overlay, as its computed background-color in each press take shows. So its press takes show the hover overlay at its default value, and its press reference clears both overlays.
