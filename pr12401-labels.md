# OverflowList fits with the rendered gap (#12401): stills (test data, local Storybook builds)

- Builds, with stamps read back from each served build: main 2ff1afc9f8d11a2899f42b8193970f638b1aebff, head 20cfc048ac2a0b2470db2a117f8dd8b0bbe9f4d9, merge-base 68510fe2bfd11dbb4e10b181ee53d378ada28bfb.
- The head's merge-base is 68510fe2bf; main 2ff1afc9f8 is 22 commits later. Between them, the Theme wrapper also sets the theme's body font size on inherited text.
- Every build uses its own OverflowList.stories.tsx (sha256 adf27436c1d74b13…, the same at all three). The OverflowActions toolbar story is not in these builds' Toolbar.stories.tsx, so every build carries the same Toolbar.stories.tsx (a1d6b8c97ba12f55…) that adds it. Product code is each SHA's own.
- Browsers: Playwright chromium 149.0.7827.55 and firefox 151.0. Light, deviceScaleFactor 2, viewport 1400×900.
- Themes come from the Storybook global (`globals=astryxTheme:<theme>`). For the 12 px root, a style `html { font-size: 12px; }` goes into the page before the story renders. The table shows the root font size the page then reports.
- Frames: the Resizable frame is set to 260 px wide, MultiRow keeps its own 280 px, and the toolbar frame is set to 380 px. After 400 ms, the list's labels are read on 12 consecutive animation frames.
- Drawn gap: the list's computed column-gap, plus the measured space between adjacent items. Assumed gap: the gap the fit uses. On main and on the merge-base it is OverflowList's fixed table of px per spacing step (step 2 = 8 px, step 1 = 4 px). On the head it is the column-gap computed on the hidden measurement copy, which the head's fit reads.
- Shown text: for each still, the text the still shows, read right before and right after it. Each glyph counts as shown when at least half of it lies inside the still and every clipping box. A glyph also needs to sit before the ellipsis of an overflowing `text-overflow: ellipsis` box. "cut from" means an ellipsis replaced the rest; "clipped from" means a box edge cut it off; "not shown" means no glyph is visible.
